# T3 — Operator Analyst 결론 요약

> **원문**: [../raw/T3-operator-analyst.md](../raw/T3-operator-analyst.md)
> 아래는 결론·권고·의사결정 근거 핵심만 추린 요약. **증거·데이터·대안 평가는 raw 참조**.

---

## C1. 유저 심리 6대 축

- **Flooding (Gottman)**: 심박수 100+ 시 인지 마비. 단순·짧은 UI 필수.
- **자기보호·Shame**: 관계 문제 공개 저항. 익명·프라이버시가 진입 필수 조건.
- **프라이버시 불안**: Consumer Reports 2023 조사 58% "파트너가 볼까 걱정" (일반 앱의 4배).
- **취약성**: Brené Brown — 노출이 치유의 시작.
- **수치심 회피**: 자기 비난 패턴 강화 주의.
- **SaaS 6원칙 수정**: 일반 앱 "빠르게·쉽게·강력하게"가 관계 앱에는 "천천히·안전하게·깊게"로 전환.

## C2. 3 페르소나 우선순위

- **민지 A (파워 유저)** — 2순위: 30대 기혼 여성, 심리학 기본 지식, 파트너 설득력 원함.
- **준호 B (위기 first-time)** — **1순위**: 30대 남성, 관계 위기 처음, 익명·즉시·간단 원함.
- **수빈 C (장기 복귀)** — 3순위: 20대 여성, 반복적 관계 문제, 커뮤니티·콘텐츠 소비.

**설계 충돌 시 B 우선**: "B 기준 설계는 A·C 수용 가능, 역은 성립 안 함" (ADR-0004 원칙).

## C3. 9단계 유저 여정 (준호 B 기준)

S1 검색·광고 노출 → S2 앱스토어 진입 → S3 첫 화면 → S4 회원가입 (선택) → S5 공감 첫 대화 → S6 갈등 입력 → S7 AI 코칭 응답 → S8 실전 시도 → S9 결과 피드백·재방문.

**Funnel 병목**: S3→S4 (회원가입 강제 시 이탈), S5→S6 (첫 대화 품질 실망), S8→S9 (실전 실패 시 탓 내재화).

## C4. 프라이버시 신뢰 신호 포트폴리오 N-1~N-13

**3종 세트 (Must-Have)**:
- **N-1**: "대화는 기기 내에서만 처리됨" 명확 표시.
- **N-3**: 데이터 흐름 시각화 (보내짐 vs 저장됨).
- **N-6**: 전체 삭제 1-tap 버튼.

그 외 N-2 (서드파티 audit) · N-4 (암호화 뱃지) · N-5 (익명 인증 옵션) · N-7 (파트너 모드 격리) · N-8 (CS 실명 요구 없음) · N-9 (ML 학습 opt-in 명시) · N-10 (오픈소스 공개 여부) · N-11 (DPO 연락처) · N-12 (연례 투명성 보고서) · N-13 (프라이버시 교육 콘텐츠).

## C5. 페르소나별 기능 매트릭스 (18 기능 × 3 페르소나)

- **B 우선 기능**: 공감 첫 대화·갈등 유형 분류·즉시 스크립트·위기 리퍼럴.
- **A 우선 기능**: 커플 동기화·Gottman 진단·상세 리포트·고도 개인화.
- **C 우선 기능**: 콘텐츠 라이브러리·커뮤니티·챌린지·친구 초대.

## C6. 복잡도 수용 임계

- **화면 깊이**: 최대 5 화면 (그 이상은 이탈).
- **탭 개수**: 최대 7 탭.
- **첫 메시지 문장**: 60-100자 (Flooding 상태).
- **응답 지연**: 3초 이내 (위기 순간).

## C7. 감정 안전 설계 5원칙 + 3단계 응답

- **원칙**: 공감 우선·판단 금지·명시적 안전 옵션·복귀 용이·자기 통제.
- **금지 표현**: "당신이 틀렸어요"·"헤어지세요"·"진단: ..."
- **3단계 응답**: 공감 → 관점 전환 → 행동 제안.

## C8. 커뮤니티·소셜 Phase 로드맵

Phase 1 (없음) → Phase 2 (read-only 큐레이션) → Phase 3 (moderated Q&A, 전문가 응답만) → Phase 4 (peer + 독성 필터).

## C9. Branch A vs B 유저 경험 (9축 체감)

대화 품질·프라이버시 신뢰·오프라인·응답 속도·개인화·파트너 공유·업데이트 투명성·자원 소비·커뮤니티.

**B가 유리**: 대화 품질·파트너 공유·커뮤니티.
**A가 유리**: 프라이버시·오프라인·투명성.
**Hybrid가 최적**: 5+ 축에서 중간 이상.

## C10. 상업화 수용성

- **Freemium**: 월 9,900 / 연 79,000 / 프리미엄 24,900원 (T4 §4 권장과 정렬).
- **민지 A**: 연 구독 10-20% 할인 선호.
- **준호 B**: 위기 순간 월 지불 즉시.
- **수빈 C**: freemium 장기 유지.

## C11. 준호 B 1순위 결론 + 북극성 지표

- **북극성 지표**: **"7일 내 Level 1 → Level 0 회복률"** (T2와 정렬).
- 지지 지표: 첫 대화 7일 이내 3회 이상 사용, 위기 리퍼럴 실행률, 파트너 합석 전환률.
